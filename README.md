# Los Santos TV Studio

Django-проект для студии новостей с ролями пользователей, лентой газет, страницей чтения выпусков и техподдержкой.

## Возможности

- регистрация и вход через Django auth
- роли: `Следящий`, `Редактор газет`, `Гость`
- создание и редактирование газет
- загрузка фото для выпуска
- страница чтения газеты
- техподдержка с ответами для роли `Следящий`
- админ-панель ролей

## Запуск

```bash
python manage.py migrate
python manage.py runserver
```

## Основные адреса

- `/accounts/register/`
- `/accounts/login/`
- `/dashboard/`
- `/newspapers/`
- `/support/`
- `/admin/`
